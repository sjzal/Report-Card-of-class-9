# Student Report Card Website

This is a simple HTML project that shows student report cards.

## Features
- Shows marks of students
- Displays grades (A+, A, B, etc.)
- Feedback for each student
- Responsive design for mobile and desktop

## Technologies Used
- HTML
- CSS

## How to Use
1. Open index.html in browser
2. View report cards
